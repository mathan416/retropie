# Amiga

RetroPie configuration files for Commodore Amiga emulation with Amiberry.

## Contents

- `es_systems.cfg` - EmulationStation system list configuration, including Amiga and Amiga CD32 entries.
- `emulators.cfg` - RetroPie emulator launch definitions for Amiberry and libretro Amiga cores.
- `amiberry_a1200.sh` - Amiberry launcher script for A1200-style configuration.
- `amiberry_cd32.sh` - Amiberry launcher script for CD32-style configuration.
- `amiberry_iain.sh` - Custom Amiberry launcher script variant.

These files are intended to be copied or adapted into the matching RetroPie configuration locations on the target system.
