# RetroPie

A repository dedicated to RetroPie setup notes, configuration files, and companion assets.

## Folders

- [Amiga](Amiga/README.md) - RetroPie and Amiberry configuration for Commodore Amiga emulation, including EmulationStation system entries, emulator launch definitions, and Amiberry launch scripts.
- [RGB Commander](RGB%20Commander/README.md) - RGB Commander configuration and LED animation assets for an arcade cabinet or RetroPie setup, including the daemon XML configuration and exported pattern files.
