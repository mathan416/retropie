# RGB Commander

RGB Commander configuration and LED pattern assets for a RetroPie arcade cabinet setup.

## Contents

- `June 2026/rgbcmdd.xml` - RGB Commander daemon configuration.
- `June 2026/rgba/` - RGBA LED pattern assets, including numbered patterns and named animation effects.
- `June 2026/flash/` - Flash sequence assets used by RGB Commander.

Restart RGB Commander after changing its XML configuration so the daemon reloads the updated settings.
